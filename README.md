# استوديو صحوة — قوالب البوستات

**رابط الاستخدام:** https://sahwa-post-maker.mohammed-kamal-eliwa.chatgpt.site

الرابط متاح للفريق مباشرة. تنزيل PNG لا يحتاج تثبيت برامج. النسخة المستقلة داخل `dist/offline.html` تعمل أيضًا بدون إنترنت.

أداة عربية بسيطة لتعبئة ثلاثة قوالب بهوية صحوة. اختر القالب فتظهر حقوله، مع معاينة مباشرة وتنزيل الصورة الجاهزة.

| القالب | الحقول |
| --- | --- |
| الأساسي | عنوان، جملة ثانوية، ٣ معلومات بعناوين اختيارية |
| المحاضرة | عنوان، جملة ثانوية، اسم الأستاذ، ٣ معلومات وصورة الأستاذ |
| الصورة | عنوان، جملة ثانوية وصورة كبيرة مع التدرج الأصلي |

## الاستخدام

افتح `dist/offline.html` في متصفح حديث، أو استخدم النسخة المنشورة. اختر القالب، اكتب المحتوى، راجع المعاينة، ونزّل PNG. جودة التنزيل الافتراضية 3240 × 3900 (٣ أضعاف مقاس القالب)، مع خيار 2160 × 2600 أو المقاس الأصلي 1080 × 1300. النص يُرسم من جديد بالدقة المطلوبة، وكذلك الصورة المرفوعة؛ تكبير خلفية أو صورة صغيرة لا يخلق تفاصيل غير موجودة في المصدر. PNG يحفظ الناتج دون ضغط يفقد التفاصيل. لإرساله على واتساب مع الحفاظ على الملف، استخدم مرفق المستند.

العنوان يقبل سطرًا أو سطرين ويضبط حجمه داخل المساحة. خيار الكشيدة يوزع تمديدات محدودة عند مواضع اتصال صحيحة، دون تغيير الحروف أو التشكيل أو مدّ الخط أفقيًا. يمكن إيقافه أو كتابة كشيدة يدويًا؛ لا تضيف الأداة كشيدة جديدة فوق كشيدة المستخدم. الجملة الثانوية تحتفظ بحجم القالب الطبيعي وتلتف إلى سطرين كحد أقصى، وتدعم Enter. النص الزائد يوقف التصدير بدل تصغير الجملة.

لكل معلومة مفتاح لإظهارها أو إخفائها مع علامتها. إيقاف المعلومة يحافظ على مسودتها، ويستثنيها من الرسم والتحقق. يمكن إيقاف المعلومات الثلاث كلها، كما يمكن إخفاء المعلومة بترك قيمتها فارغة.

في قالب المحاضرة، الصورة العادية JPG أو WebP أو PNG تبقى داخل الدائرة، مع لون الصورة الأصلي وخيار الأبيض والأسود. صورة PNG المفرغة تستخدم إطار الشخص الأصلي تلقائيًا؛ تُزال الهوامش الشفافة كي يظهر الشخص بحجم مناسب. يمكن استخدام صورة عامة داخل الدائرة عند عدم نشر صورة الأستاذ أو الأستاذة. قالب الصورة يحتفظ بالتدرج الأصلي فوق أي صورة بديلة. أدوات الحجم والتحريك تضبط الصورة؛ زر «الصورة الأصلية» يعيد صورة القالب. لكل قالب مسودة وصورة وإعدادات محفوظة على الجهاز، وتنتقل مسودة الإصدار الأول تلقائيًا للقالب الأساسي.

زر «تفريغ صورة الشخص تلقائيًا» خيار مستقل لقالب المحاضرة. يستخدم [MediaPipe Selfie Segmenter](https://ai.google.dev/edge/mediapipe/solutions/vision/image_segmenter/web_js) في المتصفح؛ صور المستخدم لا تُرفع إلى خادم معالجة. يحتاج تحميل المكتبة والنموذج إلى الإنترنت، ولا يُضمن تفريغ دون إنترنت. المخصص هو صورة شخص واضحة، وليس إزالة خلفية منظر عام. يحتفظ زر «إلغاء التفريغ» بملف المستخدم الأصلي. قد تفقد الحواف الدقيقة أو الشعر بعض التفاصيل؛ قارن النتيجة أو استخدم PNG مفرغًا يدويًا عند الحاجة إلى حواف دقيقة. الصورة المعالجة تُجهّز حتى 2560 بكسل في أطول ضلع، وهو أكثر من مساحة إطار الشخص في التصدير الأقصى.

## دليل صحوة والخطوط

الإصدار 1.2 يطبق دليل صحوة المرفق: العنابي `#752026` والعنابي الداكن `#350e15` والذهبي `#d6ad63` والأوف وايت `#f2e9e2`. يحافظ على الشعار في أعلى يسار البوست وإضاءة الخلفيات الأصلية وتوازن مساحات النص والصورة. الأيقونة الأصلية مستخرجة من الدليل؛ القالب الأساسي يحتفظ بأيقونته الموجودة، وقالب المحاضرة يضعها عند زاوية الصورة، وقالب الصورة يضعها بخفة في الخلفية. واجهة الأداة تستخدم الشعار والأيقونة الأصليين أيضًا.

- الخلفيات، الشعار، الزخارف، أقنعة الصور والعلامات الذهبية مستخرجة من ملفات Illustrator وPhotoshop الأصلية، دون إعادة رسمها.
- الجملة الثانوية واسم الأستاذ تستخدم IBM Plex Sans Arabic Regular (400)، والمعلومات تستخدم Thin (100)، وفق الدليل. الخطوط الكاملة مضمنة للعمل دون إنترنت، مع ترخيص OFL. النصوص الافتراضية والمعدلة تستخدم الأوزان نفسها؛ لا يُستبدل النص الافتراضي بصورة قديمة بوزن مختلف.
- العنوان الأصلي «العنوان الرئيسي» محفوظ كمسارات Illustrator للقالب الأساسي، وكصور من طبقات Photoshop للقالبين الآخرين، إلى أن يختار المستخدم خط العناوين المرفوع.
- الدليل يحدد [Asal Arabic](https://iwantype.com/product/asal-arabic/) للعناوين ويذكر [Milan Display](https://www.omarhassantype.dev) بديلًا. ملف PDF لا يحتوي برنامج Asal أو Milan الكامل. الخطوط المضمّنة فيه أجزاء محدودة من IBM وNoto وCanva، ولا تكفي لصنع خط للعناوين الجديدة. ملف AI يحتوي كذلك 13 شكل حرف فقط من Asal Arabic Bold.
- رفع Asal Arabic Bold أو Milan Display Black أو Black Swashes بصيغة TTF أو OTF يفعّل الخط للقوالب الثلاثة. يُفحص اسم PostScript وتوفر الحروف العربية والكشيدة وجدول تشكيل الحروف، لمنع اعتماد خط مختلف أو نسخة ناقصة. بعد الرفع يظهر اسم الخط ويُطوى صندوق الإعدادات؛ يُحفظ الملف على جهاز المستخدم.
- العناوين الجديدة تستخدم IBM Plex Sans Arabic Bold مؤقتًا افتراضيًا حتى رفع ملف العناوين، ويظهر ذلك في الواجهة وفي اسم ملف التنزيل. يمكن اختيار انتظار Asal أو Milan لإيقاف تصدير العناوين المعدلة مؤقتًا. Milan بديل مذكور في الدليل، وليس ادعاءً بالتطابق مع أشكال Asal.
- Asal خط مدفوع. حزمة Milan الرسمية التي فُحصت تحمل عبارة «Free for personal use only, modification is not allowed.»؛ لذلك لا تُنشر ملفات هذين الخطين ضمن الموقع أو المستودع. يرفع المستخدم ملفه محليًا بما يتوافق مع ترخيصه. روابط المصدر الرسمي متاحة داخل إعدادات الخط.
- محرك النص في المتصفح قد يختلف عن Illustrator في البدائل الأسلوبية والتنعيم. عند تزويد الخط الأصلي، تُراجع عينة للعناوين قبل اعتماد تطابق إخراج جديد.
- الحقول والصور والخط المرفوع تُحفظ محليًا في المتصفح؛ لا تُرسل إلى خادم معالجة. فشل الحفظ المحلي لا يمنع استخدام الأداة في الجلسة الحالية. توليد البوست دون استخدام زر التفريغ يعمل دون إنترنت من النسخة المستقلة.
- الكشيدة تستخدم بيانات اتصال الحروف من Unicode 17.0.0؛ إشعار الترخيص داخل `dist/assets/Unicode-LICENSE.txt`. مكتبة MediaPipe المثبتة على الإصدار 0.10.32 والنموذج مثبت على float16/1، وتُحمّل عند الطلب. النموذج ذو قناة ثقة واحدة للشخص، وليس قناة ثانية للخلفية.

## الملفات

- `design/template.ai`: نسخة مرجعية من الملف المرفق.
- `dist/engine.js`: تعريف القالب والتحقق من ملاءمة النص ومحرك الرسم.
- `dist/app.js`: اختيار القالب، الحقول، حفظ المسودات والصور، رفع الخط والتصدير.
- `dist/arabic-joining.js`: بيانات اتصال الحروف للكشيدة.
- `dist/portrait.js`: الهوامش الشفافة، تحميل أداة تفريغ الشخص وتركيب PNG المفرغ.
- `dist/assets/psb2/` و`dist/assets/psb3/`: العناصر المستخرجة وتعريف الحقول والأبعاد وبيانات مصدر القالب.
- `dist/index.html`: واجهة الاستخدام.
- `dist/offline.html`: نسخة كاملة تعمل من ملف واحد دون إنترنت.
- `scripts/prepare-assets.py`: استخراج عناصر القالب وتجهيز الخطوط المفتوحة.
- `scripts/prepare-psb-assets.py`: استخراج طبقات القالبين الآخرين من المرفقات الأصلية.
- `scripts/prepare-brand-guide.py`: استخراج شعار وأيقونة دليل صحوة وتجهيز IBM Regular وThin.
- `dist/assets/brand-guide.json`: ألوان الهوية وأوزان الخطوط وقواعد التكوين المطبقة.
- `scripts/build-templates.py`: تجميع القوالب والصور والخطوط المجهزة للعمل دون إنترنت.
- `scripts/build-offline.py`: تجميع نسخة HTML المستقلة.
- `tests/verify.cjs`: اختبارات لمحرك الرسم والتصدير، دون تشغيل متصفح.

## التحقق وإعادة التجميع

```bash
node --check dist/engine.js
node --check dist/app.js
npm install
npm test
npm run build
```

تعتمد الاختبارات على `@napi-rs/canvas` ويثبّته `npm install`. تشمل ٦١ فحصًا للرسم والخطوط والكشيدة، قبول أسماء خطي العناوين ورفض برامج الخطوط الناقصة، ألوان الهوية وأصولها، تطبيق Regular وThin على النصوص الافتراضية والمعدلة، ثبات حجم الجملة الثانوية، إظهار المعلومات وإخفائها، استبدال الصور وإطارها، التصدير ٣×، الهوامش الشفافة وتحويل الثقة إلى قناع شفافية. الاختبارات تعمل على Canvas خارج المتصفح؛ لا تمثل اختبار التفاعل أو تشغيل نموذج التفريغ في متصفح فعلي. تم التحقق من روابط المكتبة والنموذج وأصول WASM، لكن استدلال MediaPipe داخل متصفح لم يُختبر في بيئة التطوير الحالية. لا تتضمن الاختبارات شكل عناوين جديدة بخط Asal أو Milan الكامل لأن ملفيهما غير مضمنين؛ هذا يُراجع عند توفير الخط.

استخدام الموقع أو النسخة المستقلة لا يحتاج npm. `npm run build` يجمع العناصر الموجودة في المستودع ولا يحتاج اتصالًا. إعادة استخراج Illustrator تحتاج PyMuPDF وfontTools واتصالًا لتحميل خطوط IBM الرسمية. إعادة استخراج Photoshop تحتاج PyMuPDF وPillow وnumpy وpsd-tools وaggdraw وملفي PSB المرفقين؛ لم تُضف الملفات الكبيرة الأصلية للمستودع. لتحديد مجلد ملفات PSB:

```bash
python3 scripts/prepare-psb-assets.py /path/to/original-templates
npm run build
```

لإعادة استخراج أصول الهوية من دليل صحوة الأصلي وتجهيز أوزان IBM من المصدر الرسمي:

```bash
python3 scripts/prepare-brand-guide.py /path/to/sahwa-guide.pdf
npm run build
```

يحافظ الإصدار الحالي على عناصر القوالب الأصلية وأقنعة الصور، مع تحديث أوزان النصوص والأيقونة والأوف وايت بحسب الدليل. المقارنة القديمة لنسخة Photoshop الافتراضية تسبق هذه التعديلات؛ لا يُدّعى تطابق بكسلات التصدير الحالي مع النسخة السابقة.

المرحلة التالية: ربط نفس تعريف الحقول والتوليد بواجهة تليجرام أو استيراد جدول. لا يوجد بوت تليجرام متصل في هذه النسخة.
