# استوديو صحوة — قوالب البوستات

**رابط الاستخدام:** https://sahwa-post-maker.mohammed-kamal-eliwa.chatgpt.site

الرابط متاح للفريق مباشرة. تنزيل PNG لا يحتاج تثبيت برامج. النسخة المستقلة داخل `dist/offline.html` تعمل أيضًا بدون إنترنت.

أداة عربية بسيطة لتعبئة ثلاثة قوالب بهوية صحوة. اختر القالب فتظهر حقوله، مع معاينة مباشرة وتنزيل الصورة الجاهزة.

| القالب | الحقول |
| --- | --- |
| الأساسي | عنوان، جملة ثانوية، ٣ معلومات بعناوين اختيارية |
| المحاضرة | عنوان، جملة ثانوية، اسم الأستاذ، ٣ معلومات وصورة الأستاذ |
| الصورة | عنوان، جملة ثانوية وصورة كبيرة مع التدرج الأصلي |

## الاستخدام

افتح `dist/offline.html` في متصفح حديث، أو استخدم النسخة المنشورة. اختر القالب، اكتب المحتوى، راجع المعاينة، ونزّل PNG بمقاس 1080 × 1300. الخانة الفارغة تختفي مع علامتها الذهبية. النص الذي يتجاوز المساحة يوقف التصدير بدل قصّه.

في قالب المحاضرة يُفضّل رفع صورة PNG مفرغة للشخص. ويمكن رفع JPG أو WebP أيضًا. الصورة الجديدة تظهر بالأبيض والأسود داخل إطار القالب. قالب الصورة يقبل صورة عادية ويحتفظ بالتدرج الأصلي فوقها. أدوات الحجم والتحريك تضبط الصورة دون تغيير التصميم؛ زر «الصورة الأصلية» يعيد صورة القالب. لكل قالب مسودة وصورة محفوظتان على الجهاز، وتنتقل مسودة الإصدار الأول تلقائيًا للقالب الأساسي.

## الخطوط والحفاظ على القالب

- الخلفيات، الشعار، الزخارف، أقنعة الصور والعلامات الذهبية مستخرجة من ملفات Illustrator وPhotoshop الأصلية، دون إعادة رسمها.
- الجملة الثانوية والمعلومات تستخدم IBM Plex Sans Arabic ExtraLight وLight. الخطوط الكاملة مضمنة للعمل دون إنترنت، مع ترخيص OFL.
- العنوان الأصلي «العنوان الرئيسي» محفوظ كمسارات Illustrator للقالب الأساسي، وكصور من طبقات Photoshop للقالبين الآخرين. الجملة الثانوية واسم الأستاذ والمعلومات الافتراضية في قوالب Photoshop تحتفظ أيضًا ببكسلاتها الأصلية ما دامت لم تتغير.
- ملف AI يحتوي 13 شكل حرف فقط من Asal Arabic Bold؛ لا يحتوي ملف الخط الكامل اللازم لكتابة عناوين جديدة. رفع ملف TTF أو OTF الأصلي يفعّل خط العنوان. يُفحص اسم PostScript لمنع اعتماد خط مختلف بالخطأ.
- العناوين الجديدة تستخدم IBM Plex Sans Arabic Bold مؤقتًا افتراضيًا حتى رفع الخط الأصلي، ويظهر ذلك في الواجهة وفي اسم ملف التنزيل. رفع Asal Arabic Bold يفعّله للقوالب الثلاثة. يمكن اختيار انتظار الخط الأصلي لإيقاف تصدير العناوين المعدلة مؤقتًا.
- محرك النص في المتصفح قد يختلف عن Illustrator في البدائل الأسلوبية والتنعيم. عند تزويد الخط الأصلي، تُراجع عينة للعناوين قبل اعتماد تطابق إخراج جديد.
- الحقول والصور والخط المرفوع تُحفظ محليًا في المتصفح؛ لا تُرسل إلى خادم. فشل الحفظ المحلي لا يمنع استخدام الأداة في الجلسة الحالية.

## الملفات

- `design/template.ai`: نسخة مرجعية من الملف المرفق.
- `dist/engine.js`: تعريف القالب والتحقق من ملاءمة النص ومحرك الرسم.
- `dist/app.js`: اختيار القالب، الحقول، حفظ المسودات والصور، رفع الخط والتصدير.
- `dist/assets/psb2/` و`dist/assets/psb3/`: العناصر المستخرجة وتعريف الحقول والأبعاد وبيانات مصدر القالب.
- `dist/index.html`: واجهة الاستخدام.
- `dist/offline.html`: نسخة كاملة تعمل من ملف واحد دون إنترنت.
- `scripts/prepare-assets.py`: استخراج عناصر القالب وتجهيز الخطوط المفتوحة.
- `scripts/prepare-psb-assets.py`: استخراج طبقات القالبين الآخرين من المرفقات الأصلية.
- `scripts/build-templates.py`: تجميع القوالب والصور والخطوط المجهزة للعمل دون إنترنت.
- `scripts/build-offline.py`: تجميع نسخة HTML المستقلة.
- `tests/verify.cjs`: اختبارات لمحرك الرسم والتصدير، دون تشغيل متصفح.

## التحقق وإعادة التجميع

```bash
node --check dist/engine.js
node --check dist/app.js
npm install
npm test
npm run build
```

تعتمد الاختبارات على `@napi-rs/canvas` ويثبّته `npm install`. تشمل ٣٨ فحصًا للرسم والخطوط، الحقول الظاهرة، استبدال الصور وضبطها واستعادتها، وإخفاء العناصر الفارغة ومنع تجاوز النص. الاختبارات تعمل على Canvas خارج المتصفح؛ لا تمثل اختبار التفاعل في متصفح فعلي.

استخدام الموقع أو النسخة المستقلة لا يحتاج npm. `npm run build` يجمع العناصر الموجودة في المستودع ولا يحتاج اتصالًا. إعادة استخراج Illustrator تحتاج PyMuPDF وfontTools واتصالًا لتحميل خطوط IBM الرسمية. إعادة استخراج Photoshop تحتاج PyMuPDF وPillow وnumpy وpsd-tools وaggdraw وملفي PSB المرفقين؛ لم تُضف الملفات الكبيرة الأصلية للمستودع. لتحديد مجلد ملفات PSB:

```bash
python3 scripts/prepare-psb-assets.py /path/to/original-templates
npm run build
```

مقارنة التصدير الافتراضي بملفات Photoshop المرفقة أعطت متوسط فرق RGB أقل من مستوى واحد من ٢٥٥ للقالبين. هذا يقيس العناصر الافتراضية؛ العناوين الجديدة بخط مؤقت والصور البديلة ليست جزءًا من مقارنة المطابقة.

المرحلة التالية: ربط نفس تعريف الحقول والتوليد بواجهة تليجرام أو استيراد جدول. لا يوجد بوت تليجرام متصل في هذه النسخة.
